# مساعد التاجر (Merchant OS)

نظام تشغيل بسيط للتاجر الصغير المصري — POS سريع + خزنة + ديون + مخزون + مساعد يفهم كلامك.
**قاعدة البيانات هي مصدر الحقيقة، والمساعد لا يخترع أرقامًا ولا يعدّل شيئًا بدون إذن.**

## تشغيل المشروع

```bash
npm install
# (قاعدة البيانات: PostgreSQL محلي — راجع .env)
npx drizzle-kit push          # تطبيق المخطط
npm run dev                   # أو npm run build && npm start
```

عند أول طلب تُزرع بيانات تجريبية تلقائيًا (3 أنشطة كاملة: سوبر ماركت / عطارة / محل عام).

## المبادئ المعمارية

- **Ledger-first**: لا أرصدة قابلة للتعديل — كل تغيير حركة (cash_movements, customer_ledger, supplier_ledger, stock_movements) وكل رصيد = مجموع الحركات.
- **المعاملات ذرّية**: البيع/الشراء/الإلغاء/المرتجع معاملات DB واحدة (Drizzle `transaction`).
- **Idempotency**: فواتير من جهاز offline تحمل `clientRef` — لا تتكرر أبدًا عند المزامنة (POS يحفظ محليًا في localStorage ويعيد الإرسال عند عودة الاتصال).
- **لا معلومات مخترعة**: البيع السريع لا يمس المخزون، والشراء بدون أصناف لا يزيد مخزونًا.
- **الصلاحيات**: المالك/المدير/الكاشير/أمين المخزن — الكاشير لا يرى الأرباح ولا يلغي فواتير، والمساعد يحترم نفس المصفوفة.
- **المساعد حتمي أولًا**: موجّه قواعد/Regex ينفذ استعلامات SQL حقيقية وأوامر محرّكة عبر نفس Transaction Engine — لا LLM خلف الأرقام. البنية جاهزة لطبقة LLM لاحقًا لنفس الأدوات.
